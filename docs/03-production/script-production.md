# Script Production

Version: 1.0

---

# Purpose

Script Production defines the process of transforming an approved Episode Plan into a complete production-ready script.

Unlike the Dialogue Generator, which creates conversations, Script Production assembles every narrative component into a structured script suitable for production.

The script becomes the primary production document for storyboard creation, voice production, animation, and post-production.

---

# Objective

Produce a complete, consistent, and production-ready script that accurately represents the approved Episode Plan.

Script Production answers one fundamental question:

> **"How should this episode be written for production?"**

The script should require only creative review before entering the next production stage.

---

# Position in the Production Workflow

```
Episode Plan

↓

Scene Plan

↓

Dialogue

↓

Script Production

↓

Storyboard Production

↓

Visual Production

↓

Voice Production
```

Script Production is the first stage of production after AI generation has been approved.

---

# Responsibilities

Script Production is responsible for:

- assembling the complete script
- organizing scenes
- integrating dialogue
- describing actions
- defining transitions
- preparing production notes

Script Production does **not** determine story structure.

That responsibility belongs to the planning modules.

---

# Input

Script Production receives:

- approved Episode Plan
- approved Scene Plan
- approved Dialogue
- Universe Bible
- Production Bible

Example:

```
Episode Plan

+

Scene Plan

+

Dialogue

↓

Script Production
```

# Script Structure

Every script follows a standardized structure.

```
Episode Information

↓

Synopsis

↓

Scene Breakdown

↓

Scene Details

↓

Dialogue

↓

Production Notes

↓

End
```

A consistent structure simplifies production and review.

---

# Episode Information

Basic metadata describing the episode.

Examples:

- series title
- season
- episode number
- episode title
- version
- author
- production status

This information uniquely identifies the script.

---

# Episode Synopsis

Provide a concise overview of the episode.

The synopsis explains:

- the main objective
- the central conflict
- the outcome

It allows production teams to understand the episode before reading the full script.

---

# Scene Breakdown

List every scene in sequential order.

Example:

```
Scene 01

Village Entrance

↓

Scene 02

Marketplace

↓

Scene 03

Old Warehouse
```

This serves as the production roadmap.

---

# Scene Details

Each scene contains structured information.

Examples:

- location
- participating characters
- objective
- emotional tone
- action summary
- transition

The scene description explains **what happens**, not how it should be filmed.

---

# Action Description

Action descriptions explain what characters do.

Examples:

- entering a location
- observing an object
- helping another character
- reacting emotionally
- solving a problem

Descriptions should be concise and unambiguous.

---

# Dialogue

Dialogue is inserted into the appropriate scene.

Every dialogue block includes:

- speaker
- spoken lines
- emotional intent
- narrative purpose

Dialogue should remain identical to the approved Dialogue output unless intentionally revised.

---

# Scene Transition

Transitions connect scenes naturally.

Examples:

- time passes
- location changes
- character movement
- emotional transition

Transitions improve narrative flow.

---

# Production Notes

Optional notes supporting downstream production.

Examples:

- important props
- recurring visual references
- sound cues
- continuity reminders
- visual emphasis

Production notes assist the production team without changing the story.

---

# Script Validation

Before approval, the script is verified for:

- scene completeness
- dialogue completeness
- character consistency
- location consistency
- narrative continuity
- formatting consistency

Only validated scripts continue to Storyboard Production.

---

# Revision Workflow

If revisions are required, only affected sections should be updated.

Example:

```
Dialogue Updated

↓

Affected Scene Updated

↓

Script Regenerated

↓

Remaining Scenes Preserved
```

Targeted revisions reduce unnecessary work.

---

# Relationship with Other Components

```
Episode Planner

↓

Scene Generator

↓

Dialogue Generator

↓

Script Production

↓

Storyboard Production
```

Planning determines **what** happens.

Generation creates the content.

Script Production assembles everything into a production-ready document.

---

# Design Principles

Script Production follows these principles:

- Canon First
- Approved Before Produced
- Structured Documentation
- Production Ready
- Traceable Changes

The script should faithfully represent the approved creative intent.

---

# Summary

Script Production transforms approved planning artifacts and generated dialogue into a complete production-ready script.

By assembling scenes, actions, dialogue, and production notes into a standardized document, it creates the authoritative source for all downstream production activities.

The script is not merely a written story.

It is the master production document from which storyboards, visuals, voices, and final episodes are created.
