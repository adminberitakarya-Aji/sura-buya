# Visual Production

Version: 1.0

---

# Purpose

Visual Production transforms approved storyboards into production-ready visual assets.

Rather than deciding what the story should look like, Visual Production executes the visual plan defined by the Storyboard while preserving the artistic identity established in the Visual Bible.

Every visual asset should faithfully represent the approved universe.

---

# Objective

Produce consistent, high-quality visual assets for the series.

Visual Production answers one fundamental question:

> **"How should this story be visually realized?"**

The output should be ready for animation, motion production, publishing, or other downstream production processes.

---

# Position in the Production Workflow

```
Script Production

↓

Storyboard Production

↓

Visual Production

↓

Voice Production

↓

Quality Assurance
```

Visual Production begins only after the storyboard has been approved.

---

# Responsibilities

Visual Production is responsible for:

- producing character artwork
- producing environment artwork
- producing props
- producing scene illustrations
- maintaining visual consistency
- preparing production-ready visual assets

Visual Production does **not** redesign characters or alter the approved visual identity.

---

# Input

Visual Production receives:

- approved storyboard
- Character Bible
- World Bible
- Visual Bible
- Production Bible

Example:

```
Storyboard

+

Visual Bible

+

Character Bible

↓

Visual Production
```

---

Example:

---

# Visual Asset Categories

Visual Production creates multiple categories of assets.

---

## Character Assets

Visual representations of recurring and episode-specific characters.

Examples:

- character poses
- facial expressions
- action poses
- costume variations
- expression sheets

Character appearance must remain consistent across all episodes.

---

## Environment Assets

Visual representations of locations.

Examples:

- villages
- forests
- rivers
- interiors
- landmarks

Every location should follow the World Bible and Visual Bible.

---

## Prop Assets

Objects used within scenes.

Examples:

- tools
- books
- maps
- vehicles
- furniture
- food

Props should remain visually consistent throughout the series.

---

## Scene Assets

Complete visual compositions prepared from storyboard shots.

Examples:

- establishing scenes
- dialogue scenes
- action scenes
- emotional scenes

Scene assets combine characters, environments, and props into a unified visual.

---

## Supporting Assets

Additional visual elements used during production.

Examples:

- icons
- symbols
- overlays
- title cards
- transitions
- visual effects references

Supporting assets improve production efficiency.

---

# Visual Consistency

Every asset should comply with the Visual Bible.

Validation includes:

- character proportions
- clothing
- colors
- architecture
- environment style
- recurring visual motifs

Consistency strengthens audience recognition.

---

# Asset Reuse

Whenever possible, existing approved assets should be reused.

Examples:

```
Recurring Character

↓

Existing Character Sheet

↓

New Pose

↓

Scene Illustration
```

or

```
Village Market

↓

Existing Background

↓

Minor Updates

↓

Episode Scene
```

Reusing assets improves efficiency while preserving consistency.

---

# Production Process

Visual Production follows a structured sequence.

```
Storyboard

↓

Identify Required Assets

↓

Retrieve Existing Assets

↓

Create Missing Assets

↓

Validate Visual Consistency

↓

Assemble Visual Package
```

Every step should be traceable.

---

# Visual Validation

Before approval, every visual asset is verified for:

- storyboard alignment
- character consistency
- location consistency
- prop consistency
- visual style consistency
- production completeness

Only validated assets proceed to the next production stage.

---

# Revision Workflow

When revisions occur, only affected assets should be regenerated.

Example:

```
Storyboard Updated

↓

Scene 04 Updated

↓

Affected Visual Assets Updated

↓

Remaining Assets Preserved
```

This minimizes unnecessary production work.

---

# Relationship with Other Components

```
Storyboard Production

↓

Visual Production

↓

Voice Production

↓

Quality Assurance
```

Storyboard Production defines the visual plan.

Visual Production creates the visual assets.

Voice Production synchronizes audio with the visuals.

Quality Assurance validates the complete production package.

---

# Design Principles

Visual Production follows these principles:

- Canon First
- Visual Bible First
- Consistency Over Variety
- Reuse Before Recreate
- Production Ready

Every visual decision should reinforce the identity of the Suro & Buya universe.

---

---

# Summary

Visual Production transforms approved storyboards into production-ready visual assets that faithfully represent the Universe Bible.

By producing consistent characters, environments, props, and scene compositions while maximizing asset reuse, Visual Production creates the visual foundation for animation, publishing, and future episodes.

Every visual asset should be traceable to an approved storyboard, aligned with the Visual Bible, and ready for downstream production.
