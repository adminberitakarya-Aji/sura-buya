# Production Workflow

Version: 1.0

---

# Purpose

The Production Workflow defines how approved creative artifacts are transformed into publishable content.

Unlike the Creator Workflow, which focuses on creativity, and the Engine Workflow, which focuses on AI orchestration, the Production Workflow focuses on execution.

Its goal is to ensure that every published asset remains faithful to the approved Universe Bible.

---

# Objective

Transform approved production artifacts into final deliverables that are ready for distribution.

The Production Workflow answers one fundamental question:

> **"How do approved ideas become finished content?"**

Only artifacts that have successfully passed the Review stage may enter production.

---

# Position in the Overall Workflow

```
Creator Workflow

↓

Engine Workflow

↓

Review

↓

Production Workflow

↓

Publishing
```

Production always begins after creator approval.

---

# Production Philosophy

Production follows one simple principle:

> **Approved Before Produced.**

Nothing enters production unless it has been reviewed and approved by the creator.

The AI Engine assists production but never bypasses approval.

# Workflow Stages

## 1. Production Planning

The workflow begins by determining what needs to be produced.

Planning includes:

- production scope
- required assets
- dependencies
- priorities
- production schedule

The goal is to organize work before asset creation begins.

---

## 2. Asset Preparation

The engine gathers all approved references.

Examples include:

- Character Bible
- World Bible
- Story Bible
- Visual Bible
- Production Bible
- Episode Plan
- Approved Script

Only approved references are used.

---

## 3. Asset Production

Production assets are created according to the project requirements.

Examples include:

- scripts
- storyboards
- illustrations
- animations
- voice recordings
- subtitles
- promotional assets

Every asset should be traceable back to an approved source.

---

## 4. Quality Assurance

Completed assets are validated before packaging.

Quality checks include:

- canon consistency
- visual consistency
- script consistency
- production completeness
- technical quality

Assets requiring revision return to production.

---

## 5. Production Package

Validated assets are organized into a complete production package.

Example:

```
Episode 08

├── Final Script
├── Storyboard
├── Character References
├── Background References
├── Voice Script
├── Subtitle
├── Thumbnail
└── Metadata
```

The package represents a complete production unit.

---

## 6. Publishing

The final production package is prepared for distribution.

Publishing may include:

- exporting assets
- publishing metadata
- scheduling releases
- content distribution
- archival

Publishing is outside the AI generation process.

---

- final script
- storyboard

- animation assets
- voice assets
- subtitles
- promotional materials
- publishing metadata

Outputs should be complete and production-ready.

---

# Human Responsibilities

The creator remains responsible for:

- creative approval
- production priorities
- artistic direction
- publication decisions

Production never removes creator ownership.

---

# Engine Responsibilities

The AI Engine supports production by:

- organizing assets
- validating consistency
- preparing production files
- generating supporting materials
- maintaining traceability

The engine assists execution without replacing production teams.

# Design Principles

The Production Workflow follows these principles:

- Canon First
- Human Approval
- Traceable Production
- Reusable Assets
- Quality Before Publishing

Consistency is more important than production speed.

---

# Summary

The Production Workflow is the execution layer of the Suro & Buya production engine.

It transforms approved creative artifacts into production-ready assets through structured planning, asset preparation, quality assurance, and packaging.

By separating production from creation and AI orchestration, the workflow maintains quality, protects creator ownership, and ensures that every published asset remains faithful to the Universe Bible.
