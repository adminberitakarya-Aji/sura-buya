# Storyboard Production

Version: 1.0

---

# Purpose

Storyboard Production transforms an approved production script into a visual storytelling plan.

Rather than creating final artwork or animation, the storyboard defines how the story will be presented visually, scene by scene and shot by shot.

It serves as the bridge between narrative production and visual production.

---

# Objective

Produce a structured storyboard that accurately represents the approved script while preserving the visual identity defined in the Universe Bible.

Storyboard Production answers one fundamental question:

> **"How should this episode be visualized?"**

The storyboard provides the visual blueprint for every downstream production activity.

---

# Position in the Production Workflow

```
Script Production

↓

Storyboard Production

↓

Visual Production

↓

Voice Production

↓

Quality Assurance
```

Storyboard Production begins only after the production script has been approved.

---

# Responsibilities

Storyboard Production is responsible for:

- breaking scenes into shots
- defining visual composition
- planning visual flow
- identifying camera intent
- organizing visual continuity
- preparing the storyboard package

Storyboard Production does **not** create final illustrations or animations.

Its responsibility is visual planning.

---

# Input

Storyboard Production receives:

- approved production script
- Character Bible
- World Bible
- Visual Bible
- Production Bible

Example:

```
Production Script

+

Visual Bible

+

Character Bible

↓

Storyboard Production
```

---

The output is a storyboard package.

Example:

```

↓

Scene 01

Shot 01

Shot 02

Shot 03

↓

↓

```

The storyboard becomes the primary reference for Visual Production.

---

# Storyboard Structure

Every storyboard follows a standardized hierarchy.

```
Episode

↓

Scene

↓

Shot

↓

Frame Description

↓

Production Notes
```

This hierarchy provides a consistent production workflow.

---

# Scene Breakdown

Each storyboard begins with a scene overview.

Examples include:

- scene number
- location
- objective
- participating characters
- emotional tone

The scene overview provides context before individual shots.

---

# Shot Planning

Every scene is divided into logical shots.

Each shot should represent one meaningful visual moment.

Examples:

```
Shot 01

Character Arrival

↓

Shot 02

Conversation

↓

Shot 03

Discovery
```

Shots should follow the natural progression of the script.

---

# Frame Description

Each shot contains a visual description.

Examples include:

- character positions
- important actions
- environment
- props
- composition
- focal point

Descriptions should communicate intent rather than artistic style.

---

# Visual Continuity

The storyboard maintains consistency throughout the episode.

Checks include:

- character appearance
- costumes
- locations
- props
- weather
- time of day

Visual continuity prevents production errors.

---

# Camera Intent

The storyboard may include optional visual direction.

Examples:

- establishing shot
- close-up
- medium shot
- wide shot
- tracking shot
- overhead view

These descriptions communicate storytelling intent rather than mandatory cinematography.

---

# Transition Planning

Transitions define how one shot connects to the next.

Examples:

- cut
- fade
- dissolve
- match action
- visual continuation

Transitions should support the pacing of the story.

---

# Storyboard Validation

Before approval, the storyboard is verified for:

- script alignment
- visual continuity
- character consistency
- location consistency
- complete scene coverage
- production readiness

Only validated storyboards proceed to Visual Production.

---

# Revision Workflow

Changes should affect only the necessary storyboard sections.

Example:

```
Scene Updated

↓

Affected Shots Updated

↓

Storyboard Revised

↓

Remaining Shots Preserved
```

Localized revisions improve production efficiency.

---

# Relationship with Other Components

```
Script Production

↓

Storyboard Production

↓

Visual Production
```

The production script defines the narrative.

The storyboard defines the visual presentation.

Visual Production creates the final assets.

Each module has a clearly defined responsibility.

---

# Design Principles

Storyboard Production follows these principles:

- Canon First
- Script First
- Visual Consistency
- Structured Planning
- Production Ready

The storyboard should communicate visual intent clearly while remaining faithful to the approved script.

---

# Future Expansion

Future versions may support:

- AI-assisted storyboard generation
- automatic shot suggestions
- storyboard visualization
- camera path planning
- animatics generation
- production timing estimation
- collaborative storyboard review

These capabilities enhance production without changing the storyboard workflow.

---

# Summary

Storyboard Production transforms an approved production script into a structured visual blueprint for the episode.

By organizing scenes into shots, defining visual continuity, and documenting production intent, the storyboard ensures that every visual asset remains consistent with the Universe Bible and the approved script.

The storyboard is not the final artwork.

It is the production blueprint that guides every visual decision throughout the creation of the Suro & Buya series.
