# Character Bible

Version: 1.0

---

# Purpose

The Character Bible is the authoritative repository for every character that exists within the Suro & Buya universe.

It defines who each character is, how they think, how they behave, how they grow, and how they interact with others.

The Character Bible ensures that every appearance of a character remains consistent across every story, season, episode, and production asset.

---

# Objective

Provide a complete and canonical definition of every character.

The Character Bible answers one fundamental question:

> **"Who is this character?"**

Every AI-generated story, dialogue, and visual representation must be derived from this document.

# Scope

The Character Bible contains information about:

- main characters
- supporting characters
- recurring characters
- temporary characters

Every named character should have an official profile.

---

# Identity

Defines the basic identity of a character.

Examples include:

- character ID
- full name
- nickname
- age
- gender
- occupation
- role in the story
- first appearance

Identity uniquely distinguishes one character from another.

---

# Background

Describes the character's history.

Examples:

- birthplace
- family
- education
- occupation
- important life events
- past experiences

Background explains why the character behaves the way they do.

---

# Personality

Defines the character's core traits.

Examples:

- strengths
- weaknesses
- habits
- fears
- beliefs
- values
- emotional tendencies

Personality should remain consistent unless intentionally changed through the story.

---

# Goals

Defines what motivates the character.

Examples:

- long-term goals
- short-term goals
- personal ambitions
- responsibilities
- internal conflicts

Goals drive decision-making throughout the story.

---

# Relationships

Defines how characters relate to one another.

Examples:

- family
- friends
- rivals
- mentors
- students
- allies
- antagonists

Relationships should evolve naturally while preserving continuity.

---

# Abilities

Defines what the character is capable of.

Examples:

- physical abilities
- knowledge
- professional skills
- unique talents
- limitations

Abilities should remain consistent throughout the series.

---

# Character Arc

Describes how the character develops over time.

Examples:

- initial state
- major turning points
- emotional growth
- personal transformation
- current state

Character development should follow the Story Bible.

---

# Dialogue Style

Defines how the character communicates.

Examples:

- vocabulary
- speaking rhythm
- tone
- favorite expressions
- emotional expression
- communication style

Dialogue should immediately feel recognizable to the audience.

---

# Visual References

The Character Bible references visual identity defined in the Visual Bible.

Examples include:

- appearance
- clothing
- hairstyle
- colors
- accessories
- expressions

Visual details should not contradict the Visual Bible.

---

# Character Metadata

Every character should include metadata.

Examples:

- character ID
- status
- first appearance
- latest appearance
- version
- approval status

Metadata supports traceability and version control.

# Change Management

Character changes must be controlled.

Changes include:

- personality updates
- new relationships
- visual redesign
- character development
- status changes

Every change should:

- be reviewed
- be approved
- receive a new version
- include change history

---

# Design Principles

The Character Bible follows these principles:

- Character First
- Canon First
- Consistent Personality
- Explainable Behavior
- Version Controlled

Characters should evolve intentionally, never randomly.

# Summary

The Character Bible is the canonical definition of every character in the Suro & Buya universe.

By documenting identity, background, personality, relationships, abilities, goals, character development, and dialogue style, it ensures that every character remains consistent across stories, seasons, episodes, and production assets.

Characters are more than names.

They are living entities whose identity is preserved through the Character Bible, making it one of the most important foundations of the entire Universe Bible.
