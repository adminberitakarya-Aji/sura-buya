# Production Bible

Version: 1.0

---

# Purpose

The Production Bible is the authoritative repository that defines how the Suro & Buya universe is produced.

While the Character Bible defines who the characters are, the World Bible defines where they live, the Story Bible defines what happens, and the Visual Bible defines how everything looks, the Production Bible defines **how everything is created, managed, and delivered**.

It establishes the production standards that ensure every episode is produced consistently regardless of team size or production tools.

---

# Objective

Provide a standardized production framework that transforms approved creative artifacts into publishable content.

The Production Bible answers one fundamental question:

> **"How should this universe be produced?"**

Every production activity should follow this document.
