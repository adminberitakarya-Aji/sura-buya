# Dialogue Generator

Version: 1.0

---

# Purpose

The Dialogue Generator transforms validated Scene Plans into natural, character-driven conversations.

Rather than generating dialogue in isolation, the Dialogue Generator uses the complete Working Context, Scene Plan, and Universe Bible to ensure that every line reflects each character's personality, relationships, emotional state, and current story situation.

Dialogue is not merely conversation.

Dialogue is the primary vehicle through which characters reveal who they are.

---

# Objective

Generate dialogue that faithfully represents the characters while advancing the story.

The Dialogue Generator answers one fundamental question:

> **"What should each character say in this moment?"**

Every line of dialogue should have narrative purpose.

# Dialogue Components

Every dialogue sequence contains several structured elements.

---

## Speaker

Identify who is speaking.

Example:

```
Suro

Buya

Pak Lurah
```

Every line must belong to a specific character.

---

## Dialogue

The spoken sentence.

Dialogue should reflect:

- personality
- education
- background
- emotional state
- current objective

Characters should never sound identical.

---

## Emotional Intent

Every line should communicate an emotional purpose.

Examples:

- encouragement
- humor
- concern
- curiosity
- anger
- disappointment
- gratitude
- determination

Dialogue should express emotion naturally rather than explicitly describing it.

---

## Narrative Purpose

Each exchange should contribute to the story.

Examples:

- reveal information
- build relationships
- create tension
- resolve conflict
- foreshadow events
- motivate action

Dialogue without narrative purpose should be removed.

---

## Scene Transition

The dialogue should naturally guide the audience toward the next scene.

Conversation should never end abruptly unless intentionally required by the story.

---

# Dialogue Principles

The Dialogue Generator follows several core principles.

---

## Character Voice

Every character has a unique voice.

Differences may include:

- vocabulary
- sentence length
- speaking rhythm
- humor
- politeness
- confidence

Readers should recognize a character even without seeing the speaker's name.

---

## Character Consistency

Dialogue must remain consistent with the Character Bible.

Examples:

- beliefs
- personality
- knowledge
- experience
- relationships

Dialogue should never contradict established characterization.

---

## Emotional Consistency

Characters should react naturally to events.

Emotional transitions should feel earned rather than sudden.

Example:

```
Fear

↓

Relief

↓

Gratitude
```

The progression should match the scene's emotional arc.

---

## Context Awareness

Dialogue should reflect the current situation.

Characters should acknowledge:

- location
- ongoing events
- previous conversations
- relationships
- recent story developments

Conversation should never ignore important context.

---

## Natural Conversation

Dialogue should sound authentic.

Avoid:

- unnecessary exposition
- repetitive information
- unnatural speeches
- characters explaining things they already know

Conversation should resemble real interaction while remaining purposeful.

# Validation

Before dialogue is accepted, the engine verifies:

- character voice consistency
- emotional consistency
- relationship consistency
- narrative contribution
- alignment with the Scene Plan
- canon consistency

Only validated dialogue proceeds to the final consistency check.

The Dialogue Generator transforms structured Scene Plans into natural, character-driven conversations that faithfully represent the Universe Bible.
